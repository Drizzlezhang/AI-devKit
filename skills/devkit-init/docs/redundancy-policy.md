# 冗余检测与禁用

在规划或安装完成后，你必须检查当前已安装能力中的功能重叠情况。

## 必查重叠类别
例如但不限于：
- 多个代码审查 skill
- 多个任务管理 skill
- 多个计划生成 skill
- 多个调试增强 skill
- 多个相同职责的 MCP

## 处理原则
- 保留更通用、更稳定、更贴合当前项目的高优先级项
- 禁用低优先级或重复项
- 不让多个重复 skill 同时暴露给模型

## 可选禁用方式
根据实际环境选择最合适方法：
- 在 `settings.json` 中配置禁用
- 重命名或移出对应 `SKILL.md`
- 通过插件/市场配置关闭

## 输出要求
必须说明：
- 哪些项重复
- 为什么保留 A 而禁用 B
- 禁用动作的影响范围
